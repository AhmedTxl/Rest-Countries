# REST Countries API - Frontend Mentor Challenge

## 🌍 Overview

This project is a **Frontend Mentor** challenge that involves building a responsive web application using the **REST Countries API**. The app fetches and displays information about all the countries in the world, including details such as population, region, capital, and flag.

## 🎯 Features

- Fetch and display country data from the [REST Countries API](https://restcountries.com/).
- Search for countries by name.
- Filter countries by region.
- View detailed country information, including borders and native names.
- Responsive design for mobile and desktop screens.
- Light and dark mode toggle.

## 🛠 Tech Stack

- **Framework:** Vue.js
- **Styling:** TailwindCSS
- **State Management:** Vue Composition API
- **API:** REST Countries API
- **Build Tool:** Vite

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```sh
git clone https://github.com/AhmedTxl/rest-countries.git
cd rest-countries
```

### 2️⃣ Install Dependencies

```sh
npm install
```

### 3️⃣ Start Development Server

```sh
npm run dev
```

The app will be available at `http://localhost:5173/`.
